# 参数

## 图源瓦片大小

数值越小越清晰
android 版本瓦片大小无法设置为 256，只能设置为512

## android 与 IOS 链接格式

IOS新版本已经无所谓是否带 `$`，已支持组合图层

```c
`$s` 表示服务器，在 xml 文件中的格式为 `servers=[01,02,03,04]`
android, 带`$`
https://wprd{$s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&style=8&x={$x}&y={$y}&z={$z}&scl=1&ltype=4
IOS
https://wprd{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&style=8&x={x}&y={y}&z={z}&scl=1&ltype=4
```
